# /app

Minimal task board application for the Conway's Law experiment.

## Quick start

```bash
cd app
npm install
npm start      # starts server on http://localhost:3000
npm test       # runs all tests
```

## Stack

- Node.js (no TypeScript)
- Express 4
- better-sqlite3 (SQLite)
- Node built-in test runner

See `.ai-team/decisions/inbox/rusty-stack-and-architecture.md` for rationale.
